# Contributing to Quiz Answerer

Thank you for your interest in contributing to Quiz Answerer! 🎉

## How to Contribute

### Reporting Bugs

If you find a bug, please create an issue with:
- Clear description of the problem
- Steps to reproduce
- Expected vs actual behavior
- Android version and device model
- Screenshots if applicable

### Suggesting Features

We welcome feature suggestions! Please create an issue describing:
- The feature you'd like to see
- Why it would be useful
- How it might work

### Code Contributions

1. **Fork the repository**
2. **Create a feature branch**: `git checkout -b feature/your-feature-name`
3. **Make your changes**:
   - Follow Kotlin coding conventions
   - Add comments for complex logic
   - Test on multiple Android versions if possible
4. **Commit your changes**: `git commit -m "Add your feature"`
5. **Push to your fork**: `git push origin feature/your-feature-name`
6. **Create a Pull Request**

### Code Style

- Use Kotlin idioms and best practices
- Follow Android development guidelines
- Keep functions small and focused
- Add KDoc comments for public APIs
- Use meaningful variable names

### Testing

Before submitting:
- Test on different screen sizes
- Test with various question formats
- Verify OCR accuracy
- Check error handling
- Ensure no memory leaks

### Areas for Improvement

We'd especially appreciate contributions in:
- Support for more question formats
- Improved OCR accuracy
- Better question parsing algorithms
- UI/UX enhancements
- Performance optimizations
- Accessibility improvements
- Internationalization
- Unit and integration tests

## Development Setup

1. Install Android Studio (latest stable version)
2. Clone your fork
3. Open in Android Studio
4. Get a Gemini API key for testing
5. Run on emulator or physical device

## Questions?

Feel free to open an issue for any questions about contributing!
