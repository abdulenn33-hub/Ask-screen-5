📱 WHAT WAS BUILT:

A fully functional Android application that:

  1. 📸 Captures screenshots using Android Media Projection API
  2. 🖼️  Allows selecting images from device gallery
  3. 🔍 Extracts text from images using Google ML Kit OCR
  4. 📝 Intelligently parses multiple-choice questions
  5. 🤖 Sends questions to Google Gemini AI for answering
  6. 🔊 Reads questions and answers aloud using Text-to-Speech
  7. 📊 Displays results in a clean, modern Material Design UI
