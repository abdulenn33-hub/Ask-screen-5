🎯 WHAT THIS APP DOES:

  1. 📸 Takes screenshots or loads images
  2. 🔍 Extracts text using OCR (Google ML Kit)
  3. 📝 Identifies multiple-choice questions
  4. 🤖 Gets answers from Google Gemini AI
  5. 🔊 Reads questions and answers out loud

🔧 TROUBLESHOOTING:

  Problem: Build fails
  ├─ Solution: File → Invalidate Caches / Restart
  └─ Then: Build → Clean Project → Rebuild Project

  Problem: API errors
  └─ Solution: Check internet connection & API key validity

  Problem: No text detected
  └─ Solution: Use clear, high-resolution images

  Problem: Can't hear answers
  └─ Solution: Turn up media volume (not ringer)
