🎮 HOW TO USE BACKGROUND MODE

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Enable Background Mode
┌────────────────────────────────────────┐
│  Quiz Answerer App                     │
│                                        │
│  [START BACKGROUND MODE] ◄─── Tap this│
└────────────────────────────────────────┘
         ↓
┌────────────────────────────────────────┐
│  Permission Request                    │
│  "Display over other apps?"            │
│                                        │
│  [ALLOW] ◄────────────────── Tap Allow│
└────────────────────────────────────────┘
         ↓
┌────────────────────────────────────────┐
│  Screen Capture Permission             │
│  "Start now?"                          │
│                                        │
│  [START NOW] ◄──────────── Tap to allow│
└────────────────────────────────────────┘

STEP 2: Use the Floating Button
┌────────────────────────────────────────┐
│  📱 Your Quiz App/Browser           📷│ ← Button appears
│                                        │
│  Question 1: What is the capital      │
│  of France?                           │
│                                        │
│  A. London                            │
│  B. Paris                             │
│  C. Berlin                            │
│  D. Madrid                            │
│                                        │
│         Tap button to answer ──────►  │
└────────────────────────────────────────┘
         ↓
Processing... (10-20 seconds)
         ↓
┌────────────────────────────────────────┐
│  🔔 Notification                       │
│  Found 1 question(s)                   │
│                                        │
│  Q1: B. Paris                         │
│                                        │
│  [Capture] [Stop]                     │
└────────────────────────────────────────┘
         +
┌────────────────────────────────────────┐
│  🔊 Audio Output                       │
│  "What is the capital of France?      │
│   The answer is B. Paris"             │
└────────────────────────────────────────┘

STEP 3: Continue Using
• Floating button stays visible
• Use it for any question in any app
• Results appear in notifications
• Audio plays automatically

STEP 4: Stop When Done
• Tap "STOP BACKGROUND MODE" in app
• OR tap "Stop" in notification
• Floating button disappears
• Service stops

Floating Button          ❌ No           ✅ Yes

🔐 PERMISSIONS EXPLAINED

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

SYSTEM_ALERT_WINDOW (Display over other apps)
  Purpose:  Show floating button on top of other apps
  Required: Yes (for background mode)
  Privacy:  No screen recording, only when YOU tap button
  
FOREGROUND_SERVICE_SPECIAL_USE
  Purpose:  Keep service running in background
  Required: Yes (for continuous operation)
  Privacy:  Only active when you enable background mode

All other permissions same as regular mode:
  • Internet (Gemini API)
  • Screen Capture (Screenshots on demand)
  • Notifications (Show results)
  • Media Access (Gallery selection)
